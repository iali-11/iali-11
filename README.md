<h2 align="center">🚀 Featured Projects</h2>

<h3 align="center">
  <a href="https://github.com/iali-11/infisical-eks">
    Production-Style Kubernetes Platform on Amazon EKS
  </a>
</h3>

<p align="center">
  Deployed Infisical, an open-source secrets management platform, to Amazon EKS
  with Terraform, GitOps through Argo CD, automated HTTPS, and full monitoring.
</p>

<div align="center">

⚙️ <strong>Terraform</strong>: Modular IaC split into infra and Helm roots, with S3 remote state and native locking <br>
☸️ <strong>Amazon EKS</strong>: 2 app replicas across private subnets, backed by RDS PostgreSQL and ElastiCache Redis <br>
🔄 <strong>Argo CD</strong>: GitOps deployments, with Kubernetes manifests in Git synced to the cluster automatically <br>
🌐 <strong>Traefik, cert-manager & ExternalDNS</strong>: HTTPS ingress with Let's Encrypt TLS and automatic Route 53 records <br>
🔐 <strong>External Secrets & Secrets Manager</strong>: Secrets kept out of Terraform state using ephemeral, write-only arguments <br>
📈 <strong>Prometheus & Grafana</strong>: Cluster and application monitoring via kube-prometheus-stack <br>
🚀 <strong>GitHub Actions</strong>: Pipelines to provision infrastructure and to build, scan and push images to ECR

</div>
